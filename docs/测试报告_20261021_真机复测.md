## 三、观察项（非缺陷，记录备查）

1. **s1 首次采集 fps=null（67% 有效）**：Chrome 刚切入前台、窗口未稳定渲染时首采无帧数据，按设计写 null 而非 0；probe_adb 复测 Chrome 前台 FPS 通道正常命中（55–60fps）。真游戏（名称已脱敏）全程命中。
2. **s1 gpu=0%**：该轮采集窗口内 GPU 占用数据源未返回（部分机型 dumpsys gpu 分区差异），末样本字段存在、无 JS 报错；e2e/s2 轮次 gpu 字段均按 null-or-0..100 校验通过。
3. **PresentMon warning**：PC 采集时本机已有同名 trace session（另一账户启动），产品侧已用 `fpsSource` 标记提示管理员权限，行为符合设计。
4. **端口 5037 被 Escrcpy 的 adb 占用**：项目自带 adb（perfara/collector/resources/adb/win）作为客户端连同一 server 正常识别设备，未受影响。
5. **视觉基线噪声**：`_shots/compare-table-dedupe.png` 因渲染噪声产生 127 字节差异（无产品代码变更），已还原，未产生提交。
