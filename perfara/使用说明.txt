Perfara 便携版（Windows）· 2026-10-29 整合版
==========================

一个文件夹带走：采集客户端 GUI + 数据看板服务，无需安装、无需 Python/Node 环境。
激活校验已移除：打开即用，没有「未激活，请先激活」，采集时长不受限。

【怎么用】
1. 双击 Perfara.exe（根目录那个，不是 collector 里的）
   - 看板服务与采集窗口会同时起来（服务端要多花 1~2 秒，不用等它）
   - 关闭采集客户端窗口后，看板服务会自动停止
2. 采集：顶部选设备（Android / iOS / PC）→ 选应用 → 点「开始」
   - Android 应用下拉框显示的是手机桌面上的应用名（形如「应用名 (com.example.app)」）。
     名字是从各应用安装包里读出来的，首次接上一台新手机要后台跑 1~2 分钟，
     期间可以先按包名选；跑完会自动按中文名排序，结果缓存在本机，之后打开即秒出
3. 看报告：点「报告库」（历次报告）或「打开本地报告」（最近一次），都是离线 HTML
4. 要进看板：先点「JSON」把本次数据导出成 json 文件，再打开 http://127.0.0.1:8000
   用同一个 UID 进入，在「上传测试 JSON」里选这个文件上传
   （采集端本身不联网、不自动上传）
5. 想看演示数据：浏览器打开 http://127.0.0.1:8000/?uid=perfara123

【弱网测试（随包携带）】
  采集窗口按钮组的「≈ 弱网测试」在窗口内打开弱网测试页（覆盖式二级页面，不另开窗口）。
  引擎 collector\resources\weaknet\WeakNet.exe 以无界面方式由 Perfara 拉起并托管，
  退出 Perfara 时会先关限速、解除系统代理再回收引擎，不会把机器留在断网状态。
  - 17 个场景（常规网络 / 弱网环境 / 极端环境三档）+ 13 项自定义参数，点场景即时生效
  - 点「▶ 开启限速」后状态胶囊变「限速中」；「← 返回采集」只关页面不停限速，
    顶栏按钮会变成绿色的「≈ 限速中」，随时知道还限着
  - 「▶ 开启限速」是页头唯一的启停按钮：点它会确保引擎可用 → 接管下拉框里选中的
    手机（没选手机就只限本机）→ 按当前场景开限速，结果写在页面提示条里，
    点「← 返回采集」就能直接开始采集；限速中同一按钮变「■ 停止限速」
  - 「跟随性能采集」（右栏开关，会记住上次选择）：开启后不用再单独开弱网，
    点「开始」采集时自动接管当前设备并开启限速，停止采集（含切设备/换应用、应用退出
    自动停止）时把限速、系统代理、手机代理一起收掉；只开跟随时顶栏显示「≈ 弱网·跟随」
  - 限速期间主界面顶栏会多出「⏸ 暂停弱网」「■ 停止弱网」，不用进二级页面就能操作：
    暂停只关限速（场景、系统代理、手机接管都留着，按钮变「▶ 继续弱网」）；
    停止会把限速、系统代理、手机代理一次收干净，顶栏留一行「弱网已停止」
  - 接管本机桌面程序：右栏「接管本机流量（系统代理）」
  - 接管手机（USB 直连，推荐）：数据线连上电脑 → 右栏「手机（USB 直连）」选设备 → 「接管」。
    只用 adb（adb reverse 手机 127.0.0.1:18888 → 本机引擎 8888），手机不装任何 App；
    引擎没起时点「接管」会自动把引擎拉起来，不用先点「开启限速」；
    接管时自动开启限速，点「解除」或退出 Perfara 会还原手机代理并撤掉映射。
    接管成功后会在手机上起一个守护脚本：直接拔线（或 adb 断开）时，手机几秒内自己
    撤掉系统代理恢复直连，不会出现「拔了线还上不了网」；守护装不上时界面会提示
    「拔线守护未安装」，这时请先点「解除」再拔线。
    部分 ROM 禁止 adb 写系统设置（会提示）：到开发者选项打开「禁止权限监控」
    或「USB 调试（安全设置）」（不同厂商叫法不同）后重试。
  - 接管同一 Wi-Fi 的手机 / 其他设备：右栏「局域网访问」开启，设备上把 HTTP 代理设为 <PC 的 IP>:8888
  - 只有走系统代理的流量会被限速：自己开 TCP/UDP 的程序（多数手游）不走代理，限不到
  - 弱网组合：左栏第三块「弱网组合」，把多段场景按顺序排成一条时间线（最多 5 段，
    每段选场景 + 时长，可循环），点一下即播放；播放中显示「第 2/3 段 · 场景名 · 还剩 0:42」。
    「＋ 新建」填名称、勾循环、加步骤后保存；选中组合后可「编辑」或「删除」（删除要在
    4 秒内再点一次确认）。配置与 WeakNet 图形界面共用，组合里不能再套组合
  - 弱网只影响被接管的一方，不影响 USB 上的 adb 采集，可以边限速边采集

【目录说明】
  Perfara.exe              启动器（服务与采集窗口同时拉起）
  collector\               采集客户端（Electron，已移除激活）
  server\PerfaraServer.exe 看板服务（FastAPI，也可单独运行）
  data\webperf.db          数据库（SQLite）
  logs\                    启动器与服务日志

【单独启动看板服务】
  server\PerfaraServer.exe --port 8000
  server\PerfaraServer.exe --port 8099 --host 0.0.0.0   # 局域网访问
  数据默认写在 exe 同级 data\ 下；也可 --data-dir D:\perfara

【离线与上传】
  采集端全程离线：不发外网请求，也不会自动上传。数据入库只有一条路——
  看板网页 → 「上传测试 JSON」→ 填 UID、选「JSON」导出的文件。
  collector\resources\configout\config.js 由启动器每次启动时重写，里面只有一条 uploadurl，
  客户端不读取它（改它不会把数据传到别处）。
  服务端上传接口只收 application/json 与 multipart；别的网页跨站提交会被 403 拒绝。

【本地报告】
  采集停止后，报告目录在 collector\resources\reports\
    perf.html   完整报告（指标卡片 + 统计表 + 趋势图）
    perf2.html  分组统计报告
    data.js     本次采集的数据（由客户端写入）
  直接双击 perf.html 即可离线查看。
  ※ 已内置 echarts 到同目录（echarts.min.js），断网也能出图；
    原版从 cdn.jsdelivr.net 加载，网络不通时会只剩指标卡片、表格与图表全空。

  报告里与采集过程相关的两块内容：
  - 弱网总结分析（这一轮开过限速才有）：弱网时长占比、场景/时段/接管范围/代理流量，
    以及「弱网段 vs 直连段」六项对比（帧率、达帧率、1% Low、卡顿、流量、进程 CPU）
    和按衰减幅度给出的建议。没开限速就没有这一段，老报告不受影响。
  - 性能低谷截图（N）：帧率低于本轮目标 80% 且连续 2 拍才判为低谷，自动截屏
    （冷却 10 秒、单轮最多 30 张）；FPS 曲线的低谷点上方有缩略标记，点开看大图。
    截图只存在于本机 reports\shots\ 下，不上传。
  采集窗口底部还有一条缩略图条：最多 60 张、点击全屏、Esc 关闭、重新采集时自动清空。

【已做的改动】
1. 移除采集端激活：src/activation.js 恒返回「已激活、永久有效」，
   顶栏「激活」按钮与「未激活」提示一并删除；不再读写 activitecode.json。
2. 采集端不联网：去掉上传上报，入库改走看板网页的「上传测试 JSON」；
   启动器只把本机端口写进 configout。
3. 去掉 asar 里的 mac 安装包与多余语言包，体积从 669MB 降到 518MB。
4. 弱网改为采集窗口内的二级页面，引擎随包以无界面方式托管，退出即回收。
5. 新增弱网组合（多段场景按顺序播放）与报告里的「弱网总结分析」。
6. 新增性能低谷自动截图：采集窗口缩略图条 + 实时曲线标记 + 报告画廊。
7. 启动器把子进程临时目录收进包内 .run\，启动前清空、退出后清理，
   不再往系统 %TEMP% 里丢 _MEI 解压目录。
8. Android 应用列表显示桌面名：不经 adb 的 label 接口（手机端没有），
   而是直接解 APK 里的 AndroidManifest.xml + resources.arsc，按手机语言取名，
   后台逐条解析、界面即时更新，结果按「包名 + 版本号 + 语言」缓存到本机用户目录。
9. 弱网：手机接管成功后推送拔线守护（反向监听消失即清手机代理，先写 :0 再删字段，
   顺带清 MIUI 网络配置里镜像的那份），修复「拔线后手机还断网」；弱网页新增
   「跟随性能采集」（开始采集同步开弱网、停止采集一起收掉），启停合并成一个按钮。
10. 手机接管的残留收口：接管/解除都按「已经接管的那台 + 端口」的记账走，下拉框
   切到别的手机再点「解除」也清得对；换机或换端口重连前先把上一台还原，旧映射
   和旧代理不会留到拔线；自动还原失败时提示的手动命令是
   adb shell settings put global http_proxy :0（先写 :0 才能清掉 MIUI 的网络配置副本）。
   解除失败不会丢掉记账，退出或下次接管时还会再试一次，接管前的原代理也不会忘。
11. 本机系统代理的兜底：开启「接管本机流量」前把注册表里的原值快照到用户目录，
   引擎崩溃 / 被强杀（atexit 不执行）时按快照还原并通知系统刷新；整个程序被强杀
   也没关系，下次启动会先还原再开窗口。开启限速 / 跟随采集在限速没开成时会把
   刚接管的手机退回去，不留「接管着但没限速」的半截状态。

【常见问题】
- 端口被占用：启动器会自动顺延到 8001/8002…，上传地址会同步改好。
- 双击没反应/闪退：看 logs\launcher.log；再单独运行 server\PerfaraServer.exe 看报错。
- Windows 提示"已保护你的电脑"：点「更多信息 → 仍要运行」，或把整个文件夹加白名单。
- Android 采集需要 adb 能识别设备：先在命令行跑 collector\resources\adb\adb.exe devices 确认。
- iOS 采集需要 iTunes/驱动与开发者镜像，镜像在 collector\resources\ios-tools 内。
- 手机拔线 / 重启后还上不了网：拔线由手机上的守护脚本自动恢复；手机重启会连守护一起
  清掉而代理还在，重新点一次「接管」即可恢复。手边没电脑时用手机「设置 → WLAN → 代理」
  改成「无」，或执行 adb shell settings put global http_proxy :0（只 delete 清不干净）。
- 采集程序被任务管理器强杀（账本跟着丢了）后，手机可能还指着 127.0.0.1:18888 而映射
  已经没了：重新打开 Perfara 会自动检查已连接的手机，把这种残留代理清掉，不用手工处理。
- 迁移：整个文件夹拷走即可，data\ 里就是全部数据。
